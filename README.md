1. Как запустить проект — команды для установки и запуска
- Открываем проект в ide, открываем командную строку 
- Проверяем путь, должны быть в нужной папке проекта (если нужно переходим через cd )
- Установить зависимости проекта, вводим команду: npm install , если возникнут ошибки можно через npm install --legacy-peer-deps установить зависимости 
- После установки можно запускать проект вводим команду: npm start 
Для проверки тестовой нужна команда: npm test 


2. Какой фреймворк использован — и почему выбран именно он
Выбран React тк у него есть:
-  компонентная структура
-  управление состоянием
- интеграция с ts
- много библиотек для решения задач разного вида
- проект на react легко масштабируется, следовательно есть возможность расширения функционала.
